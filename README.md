## Personal Finance Tracker – Backend Development

Developing a Personal Finance Tracker Mobile Application backend using **Java 17, Spring Boot, Spring Security, Spring Data JPA, and MySQL**.

**Key Features:**
- User registration and login with JWT authentication
- Secure password hashing using BCrypt
- Input validation using Spring Validation
- MySQL database integration with Hibernate/JPA
- RESTful API development
- Environment-based configuration for database credentials and JWT secrets

**Tech Stack:** Java, Spring Boot, Spring Security, JWT, MySQL, Spring Data JPA, Hibernate, Maven, REST APIs.

Currently building the backend modules for income and expense tracking, categories, budgets, bills, and financial reports.
